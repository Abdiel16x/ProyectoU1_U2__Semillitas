Declaración de uso de IA.

En el desarrollo del proyecto se hizo uso de herramientas de IA como apoyo en las etapas de análisis del acta de entrevista, asesoramiento para correcciones con la base de datos, conexiones de ViewModels a Views en el cliente y para generar una base para el diseño de este.

las herramientas empleadas fueron usadas como recursos complementarios para facilitar la compresión y resolver dudas e identificar posibles errores.

el uso de la IA no sustituyo el trabajo o las decisiones finales de los integrantes del equipo.

Los integrante del equipo asumimos la responsabilidad sobre el contenido, la calidad y el funcionamiento del proyecto.

En el desarrollo de este proyecto se usaron herramientas como ChatGPT, DeepSeek y GitHub Copilot en sugerencias de código.
